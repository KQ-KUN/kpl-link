# KPL Link UI 约定

页面延续 KPL 游戏中心的浅色入口、语义色、20px 主卡片圆角与 44px 最小点击目标，并以紫蓝 `#6754d9` 作为 Link 辅助色。游戏页支持深浅主题，入口 `?theme=light` 优先于已保存主题并在读取后清理 URL。

桌面路径横向展示，手机在 760px 以下改为纵向节点与边；320px、390px、768px、1024px 和 1366px 均不得产生页面横向滚动。搜索使用 combobox/listbox 语义，支持上下方向键、Enter 和 Escape。错误、有效、最短均以文字和符号共同表达，不只依赖颜色。

最终视觉仍需在真实浏览器中按 `390px` 与 `1366px` 进行人工交互和截图验收；构建和静态测试不能替代该步骤。
