Cat 与 Fly 的漏连已修复。根因是建图仅接入 2019 年以后的实战归属，仓库已有的 2016—2018 年历史逐局证据未参与建图；旧校验只检查图结构，无法发现缺失整个年代。

## 证据与修复范围

- 接入八届历史赛事的 974 条比赛记录，其中 934 条有完整阵容、40 条缺失阵容。仅通过现有已审查身份映射的 19 名选手参与补充，不按昵称猜测身份。
- 历史证据覆盖 21 对同局同队关系，其中 9 对原来缺边；图从 744 人、4,677 条边更新为 744 人、4,686 条边。

## 校验与剩余缺口

历史边逐对核对同局、同队及来源链接，避免对手交错排列导致错队，以及同赛事转会导致误连。增加真实 Cat/Fly 图的前端判定、最短距离与路径提交回归。校验器现在要求生成快照与输入数据一致；历史回归另外从原始记录独立重建全部已映射关系及来源集合。

现有现代归属有 54 条缺少可确认的稳定身份；核对现有头像标识、Guessing 别名后仍无可确认映射。历史记录有 245 个来源身份尚未映射，包括明确禁止按同名合并的早期“小羽”。完整清单在 `sourceAudit.historical.excludedIdentities`。这些记录保持排除，不能宣称全历史关系已完整。旧比赛部分来源为 WanPlus，完整性和真实性也受现有采集证据限制。

审计完成时的验证范围为本地数据、游戏逻辑、类型检查与静态构建。正式上线另由 KPL GAME 发布流程验证；线上发布状态以对应平台 commit 的 `release-meta.json`、生产 smoke 和 Actions 结果为准。

实际验证通过：7 项 Python 建图回归、15 项 Link 测试、图与源数据一致性校验、TypeScript 类型检查、Vite 构建及 `git diff --check`。真实快照中 `isTeammate(Cat, Fly)` 双向均为真，最短距离为 1，两人路径提交判定有效。
